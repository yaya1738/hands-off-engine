# 1. NATURE OF BUSINESS

## 1.1 What is Business?

**Business** is the organized effort of individuals to produce and sell goods and services for profit. At its core:

- **Value Creation**: Transforming inputs into more valuable outputs
- **Exchange**: Trading goods/services for money or other value
- **Profit Motive**: Generating returns exceeding costs
- **Risk Taking**: Uncertainty in exchange for potential reward

### The Purpose of Business

```
Traditional View: Maximize shareholder wealth
Stakeholder View: Balance interests of all stakeholders
  - Shareholders (owners)
  - Employees
  - Customers
  - Suppliers
  - Community
  - Environment
```

## 1.2 Business Structures

### Sole Proprietorship
```
Owner: Single individual
Liability: Unlimited personal liability
Taxation: Pass-through (personal tax return)
Control: Complete
Formation: Minimal paperwork

Pros: Simple, full control, easy taxes
Cons: Unlimited liability, hard to raise capital
```

### Partnership
```
Types:
- General Partnership (GP): All partners liable
- Limited Partnership (LP): Some partners limited liability
- Limited Liability Partnership (LLP): Professional liability protection

Taxation: Pass-through
Control: Shared per agreement

Pros: Shared resources, expertise
Cons: Partner disputes, liability exposure
```

### Corporation
```
C-Corporation:
- Separate legal entity
- Limited liability for shareholders
- Double taxation (corporate + dividend)
- Can issue stock, raise capital
- Perpetual existence

S-Corporation:
- Pass-through taxation
- Limited to 100 shareholders
- One class of stock
- US shareholders only
```

### Limited Liability Company (LLC)
```
Combines partnership flexibility with corporate protection
- Limited liability
- Pass-through taxation (default)
- Flexible management structure
- Operating agreement governs

Popular for: Small businesses, real estate, startups
```

# 2. ECONOMICS FUNDAMENTALS

## 2.1 Microeconomics

### Supply and Demand
```
Demand: Quantity buyers want at each price
  - Law of Demand: Price ↑ → Quantity ↓
  - Demand curve slopes downward

Supply: Quantity sellers offer at each price
  - Law of Supply: Price ↑ → Quantity ↑
  - Supply curve slopes upward

Equilibrium: Where supply = demand
  - Market-clearing price
  - No shortage or surplus
```

### Elasticity
```
Price Elasticity of Demand:
  Ed = (% change in quantity) / (% change in price)

  |Ed| > 1: Elastic (sensitive to price)
  |Ed| < 1: Inelastic (insensitive)
  |Ed| = 1: Unit elastic

Factors affecting elasticity:
  - Substitutes available
  - Necessity vs luxury
  - Time horizon
  - Proportion of income
```

### Market Structures
```
Perfect Competition:
  - Many small firms
  - Identical products
  - Price takers
  - Easy entry/exit
  - Zero economic profit long-term

Monopolistic Competition:
  - Many firms
  - Differentiated products
  - Some pricing power
  - Easy entry/exit

Oligopoly:
  - Few large firms
  - Differentiated or identical
  - Significant pricing power
  - Barriers to entry
  - Strategic interaction

Monopoly:
  - Single firm
  - Unique product
  - Price maker
  - High barriers to entry
```

## 2.2 Macroeconomics

### Key Indicators
```
GDP (Gross Domestic Product):
  Total value of goods/services produced
  GDP = C + I + G + (X - M)
  C = Consumer spending
  I = Investment
  G = Government spending
  X = Exports, M = Imports

Inflation:
  General increase in price level
  CPI (Consumer Price Index) measures
  Target: ~2% annually (most central banks)

Unemployment Rate:
  % of labor force without jobs
  Natural rate: ~4-5%
  Types: Frictional, structural, cyclical
```

### Business Cycles
```
            Peak
           /    \
          /      \ Recession
    Expansion    \
       /          \
      /            Trough
     /
  Recovery

Phases:
1. Expansion: GDP growing, employment rising
2. Peak: Maximum output, capacity constraints
3. Recession: GDP declining (2+ quarters)
4. Trough: Bottom of cycle
5. Recovery: Return to growth
```

### Monetary Policy
```
Central Bank Tools:
  - Interest rates (Fed Funds Rate)
  - Open market operations (buy/sell bonds)
  - Reserve requirements
  - Quantitative easing

Expansionary: Lower rates → stimulate economy
Contractionary: Raise rates → cool inflation
```

### Fiscal Policy
```
Government Tools:
  - Taxation
  - Government spending
  - Transfer payments

Expansionary: Increase spending / cut taxes
Contractionary: Cut spending / raise taxes

Multiplier effect:
  ΔY = ΔG × (1/(1-MPC))
  MPC = Marginal Propensity to Consume
```

## 2.3 Economic Concepts

### Opportunity Cost
```
Value of next best alternative forgone

Example:
  College education cost:
  = Tuition + Books + Foregone wages
  (Not just out-of-pocket expenses)
```

### Marginal Analysis
```
Optimal decision: Where MB = MC
  MB = Marginal Benefit
  MC = Marginal Cost

Continue activity until:
  Benefit of one more unit = Cost of one more unit
```

### Comparative Advantage
```
Produce goods with lowest opportunity cost

Even if one party is better at everything (absolute advantage),
trade benefits both when each specializes in comparative advantage

Basis for international trade
```

# 3. ACCOUNTING & FINANCIAL REPORTING

## 3.1 Financial Statements

### Balance Sheet
```
Assets = Liabilities + Shareholders' Equity

ASSETS                          LIABILITIES
─────────────────────          ─────────────────────
Current Assets:                Current Liabilities:
  Cash                           Accounts Payable
  Accounts Receivable            Short-term Debt
  Inventory                      Accrued Expenses
  Prepaid Expenses              Deferred Revenue

Non-Current Assets:            Long-term Liabilities:
  Property, Plant & Equipment    Long-term Debt
  Intangible Assets             Pension Obligations
  Investments                   Deferred Taxes
  Goodwill
                               SHAREHOLDERS' EQUITY
                               ─────────────────────
                               Common Stock
                               Additional Paid-in Capital
                               Retained Earnings
                               Treasury Stock (contra)
```

### Income Statement
```
Revenue (Sales)
  - Cost of Goods Sold (COGS)
─────────────────────────────
= Gross Profit
  - Operating Expenses
    - SG&A (Selling, General & Administrative)
    - R&D
    - Depreciation & Amortization
─────────────────────────────
= Operating Income (EBIT)
  - Interest Expense
  + Interest Income
─────────────────────────────
= Income Before Taxes
  - Income Tax Expense
─────────────────────────────
= Net Income
  ÷ Shares Outstanding
= Earnings Per Share (EPS)
```

### Cash Flow Statement
```
OPERATING ACTIVITIES:
  Net Income
  + Depreciation & Amortization (non-cash)
  - Increase in Accounts Receivable
  + Increase in Accounts Payable
  - Increase in Inventory
  ± Other working capital changes
= Cash from Operations

INVESTING ACTIVITIES:
  - Capital Expenditures (CapEx)
  - Acquisitions
  + Sale of assets
  + Sale of investments
= Cash from Investing

FINANCING ACTIVITIES:
  + Proceeds from debt
  - Debt repayments
  + Proceeds from stock issuance
  - Stock repurchases
  - Dividends paid
= Cash from Financing

Net Change in Cash = Operating + Investing + Financing
```

## 3.2 Key Financial Ratios

### Profitability Ratios
```
Gross Margin = Gross Profit / Revenue
Operating Margin = Operating Income / Revenue
Net Profit Margin = Net Income / Revenue
ROE = Net Income / Shareholders' Equity
ROA = Net Income / Total Assets
ROIC = NOPAT / Invested Capital
```

### Liquidity Ratios
```
Current Ratio = Current Assets / Current Liabilities
  > 1: Can cover short-term obligations
  Healthy: 1.5 - 2.0

Quick Ratio = (Current Assets - Inventory) / Current Liabilities
  More conservative (excludes inventory)
  Healthy: > 1.0

Cash Ratio = Cash / Current Liabilities
  Most conservative
```

### Leverage Ratios
```
Debt-to-Equity = Total Debt / Shareholders' Equity
Debt-to-Assets = Total Debt / Total Assets
Interest Coverage = EBIT / Interest Expense
  > 3: Comfortable
  < 1.5: Concerning
```

### Efficiency Ratios
```
Asset Turnover = Revenue / Average Total Assets
Inventory Turnover = COGS / Average Inventory
Days Sales Outstanding (DSO) = (AR / Revenue) × 365
Days Payable Outstanding (DPO) = (AP / COGS) × 365
Days Inventory Outstanding (DIO) = (Inventory / COGS) × 365

Cash Conversion Cycle = DSO + DIO - DPO
```

## 3.3 Accounting Principles

### GAAP vs IFRS
```
GAAP (Generally Accepted Accounting Principles):
  - US standard
  - Rules-based
  - LIFO inventory allowed
  - More detailed guidance

IFRS (International Financial Reporting Standards):
  - Global standard (140+ countries)
  - Principles-based
  - LIFO not allowed
  - Fair value emphasis
```

### Key Principles
```
Accrual Basis:
  Record when earned/incurred, not when cash moves

Matching Principle:
  Match expenses to revenues they generate

Conservatism:
  When uncertain, recognize losses early, gains later

Materiality:
  Only report items that would affect decisions

Going Concern:
  Assume business will continue operating
```

### Revenue Recognition (ASC 606)
```
Five-Step Model:
1. Identify the contract
2. Identify performance obligations
3. Determine transaction price
4. Allocate price to obligations
5. Recognize revenue when obligations satisfied
```

# 4. CORPORATE FINANCE

## 4.1 Time Value of Money

### Present Value
```
PV = FV / (1 + r)^n

Where:
  PV = Present Value
  FV = Future Value
  r = Discount rate
  n = Number of periods

Example:
  $1,000 in 5 years at 8%
  PV = 1000 / (1.08)^5 = $680.58
```

### Future Value
```
FV = PV × (1 + r)^n

Example:
  $1,000 today at 8% for 5 years
  FV = 1000 × (1.08)^5 = $1,469.33
```

### Net Present Value (NPV)
```
NPV = Σ [CF_t / (1 + r)^t] - Initial Investment

Decision rule:
  NPV > 0: Accept project
  NPV < 0: Reject project

Example:
  Initial: -$100,000
  Year 1: $40,000
  Year 2: $45,000
  Year 3: $50,000
  Rate: 10%

  NPV = -100,000 + 40,000/1.1 + 45,000/1.1² + 50,000/1.1³
      = -100,000 + 36,364 + 37,190 + 37,566
      = $11,120 → Accept
```

### Internal Rate of Return (IRR)
```
Rate where NPV = 0

Decision rule:
  IRR > Required return: Accept
  IRR < Required return: Reject

Limitations:
  - Multiple IRRs possible
  - Scale not considered
  - Assumes reinvestment at IRR
```

## 4.2 Capital Structure

### Weighted Average Cost of Capital (WACC)
```
WACC = (E/V) × Re + (D/V) × Rd × (1 - Tc)

Where:
  E = Market value of equity
  D = Market value of debt
  V = E + D (total value)
  Re = Cost of equity
  Rd = Cost of debt
  Tc = Corporate tax rate

Example:
  E = $600M, D = $400M
  Re = 12%, Rd = 6%
  Tax rate = 25%

  WACC = (600/1000) × 12% + (400/1000) × 6% × (1 - 0.25)
       = 7.2% + 1.8%
       = 9.0%
```

### Cost of Equity (CAPM)
```
Re = Rf + β × (Rm - Rf)

Where:
  Rf = Risk-free rate
  β = Beta (systematic risk)
  Rm = Expected market return
  (Rm - Rf) = Market risk premium

Example:
  Rf = 3%, β = 1.2, Rm = 10%
  Re = 3% + 1.2 × (10% - 3%) = 11.4%
```

### Modigliani-Miller Theorem
```
Without taxes:
  - Capital structure doesn't matter
  - Value independent of financing

With taxes:
  - Interest tax shield valuable
  - V_L = V_U + Tc × D

Trade-off theory:
  - Benefit: Tax shield
  - Cost: Financial distress
  - Optimal: Balance benefits and costs
```

## 4.3 Working Capital Management

### Working Capital
```
Working Capital = Current Assets - Current Liabilities

Net Working Capital requirements:
  NWC = Accounts Receivable + Inventory - Accounts Payable

Operating Cycle = DIO + DSO
Cash Cycle = Operating Cycle - DPO
```

### Cash Management
```
Motives for holding cash:
  - Transaction: Day-to-day operations
  - Precautionary: Unexpected needs
  - Speculative: Opportunities

Optimal cash balance:
  Baumol Model (like EOQ for cash)
  Miller-Orr Model (stochastic)
```

## 4.4 Capital Budgeting

### Project Evaluation Methods
```
1. Net Present Value (NPV)
   Best method - considers TVM, all cash flows

2. Internal Rate of Return (IRR)
   Rate where NPV = 0

3. Payback Period
   Time to recover initial investment
   Simple but ignores TVM

4. Discounted Payback
   Payback with discounted cash flows

5. Profitability Index
   PI = PV of future cash flows / Initial investment
   PI > 1: Accept
```

### Capital Rationing
```
When limited capital available:
1. Calculate PI for all projects
2. Rank by PI
3. Select highest PI projects within budget
```

## 7.3 Inventory Management

### Inventory Types
```
Raw Materials: Input to production
Work-in-Process (WIP): Being manufactured
Finished Goods: Ready for sale
MRO: Maintenance, repair, operations
```

### Economic Order Quantity (EOQ)
```
EOQ = √(2DS/H)

Where:
  D = Annual demand
  S = Ordering cost per order
  H = Holding cost per unit per year

Example:
  D = 10,000 units
  S = $50 per order
  H = $2 per unit per year
  EOQ = √(2 × 10,000 × 50 / 2) = 707 units
```

### Inventory Systems
```
Continuous Review (Q System):
  - Fixed order quantity
  - Variable time between orders
  - Reorder when inventory hits ROP

Periodic Review (P System):
  - Fixed review interval
  - Variable order quantity
  - Order up to target level
```

# 18. INVESTMENT & VALUATION

## 18.1 Investment Fundamentals

### Asset Classes
```

  - Debt instruments

```

### Risk and Return
```
Risk-Return Tradeoff:
  Higher expected return = Higher risk

Types of Risk:
  - Systematic (Market): Non-diversifiable
  - Unsystematic (Specific): Diversifiable

Beta (β):
  - Measure of systematic risk
  - β > 1: More volatile than market
  - β < 1: Less volatile than market
  - β = 1: Moves with market
```

## 18.2 Valuation Methods

### Discounted Cash Flow (DCF)
```
Enterprise Value = Σ [FCF_t / (1 + WACC)^t] + Terminal Value / (1 + WACC)^n

Free Cash Flow (FCF):
  EBIT × (1 - Tax rate)
  + Depreciation
  - Capital Expenditures
  - Increase in Working Capital

Terminal Value:
  - Gordon Growth: FCF_n × (1 + g) / (WACC - g)
  - Exit Multiple: EBITDA_n × Multiple
```

### Comparable Company Analysis
```
Steps:
1. Select comparable companies
2. Calculate trading multiples
3. Apply multiples to target

Common Multiples:
  - EV/Revenue
  - EV/EBITDA
  - P/E (Price/Earnings)
  - P/B (Price/Book)
```

### Precedent Transactions
```
Steps:
1. Find similar M&A transactions
2. Calculate transaction multiples
3. Apply to target

Typically higher than trading multiples
  (due to control premium)
```

## 18.3 Portfolio Management

### Modern Portfolio Theory
```
Efficient Frontier:
  - Maximum return for given risk
  - Diversification reduces risk

Portfolio Return:
  E(Rp) = Σ w_i × E(R_i)

Portfolio Variance:
  σ²p = Σ Σ w_i × w_j × σ_i × σ_j × ρ_ij
```

### Capital Asset Pricing Model (CAPM)
```
E(R_i) = R_f + β_i × (E(R_m) - R_f)

Where:
  E(R_i) = Expected return on asset
  R_f = Risk-free rate
  β_i = Beta of asset
  E(R_m) = Expected market return
  (E(R_m) - R_f) = Market risk premium
```

### Asset Allocation
```
Strategic Asset Allocation:
  - Long-term target weights
  - Based on risk tolerance, goals

Tactical Asset Allocation:
  - Short-term adjustments
  - Based on market outlook

Rebalancing:
  - Return to target weights
  - Time-based or threshold-based
```

## 18.4 Fixed Income

### Bond Basics
```
Face Value (Par): Amount at maturity
Coupon Rate: Interest rate
Maturity: When principal repaid
Yield: Return if held to maturity

Price-Yield Relationship:
  - Inverse: Higher yield = Lower price
```

### Bond Valuation
```
Price = Σ [C / (1+r)^t] + [FV / (1+r)^n]

Where:
  C = Coupon payment
  r = Yield to maturity
  FV = Face value
  n = Periods to maturity
```

### Duration
```
Measures interest rate sensitivity

Duration ≈ % change in price / % change in yield

Modified Duration = Macaulay Duration / (1 + y)

Higher duration = More price sensitivity
```
