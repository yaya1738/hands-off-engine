Multi-Brain Orchestration Layer (MBOL)
======================================

MBOL is a future orchestration layer for the Hands-Off system.
It is meant to coordinate multiple coding AIs ("brains") using JSON tasks
and to keep all code changes going through Git, tests, and existing safety gates.

This file is a placeholder overview written on 2025-11-17.
MBOL is not implemented yet; this document is just a design pointer
