# Portfolio: Hands-Off Engine

## What I Built
An autonomous AI-driven system that:
- Runs 24/7 without human intervention
- Coordinates multiple AI agents (Claude, ChatGPT, Copilot)
- Makes real financial decisions
- Self-heals when components fail
- Monitors its own health
- Learns from outcomes

## Technical Stack
- **Languages:** Python, Bash
- **AI Integration:** OpenAI API, Anthropic Claude API
- **Infrastructure:** DigitalOcean, Termux (Android)
- **Automation:** Cron, custom orchestration
- **Data:** JSON state management, JSONL logging

- Claude CLI for implementation

### Intelligent Alpha Engine
LLM-powered decision making:
- Analyzes markets with AI reasoning

### Self-Healing System
Autonomous error recovery:

- Maintains uptime without intervention

### Knowledge Management
Cross-session intelligence:
- Documented learnings persist
- Each session builds on previous
- System gets smarter over time
- Institutional knowledge encoded
