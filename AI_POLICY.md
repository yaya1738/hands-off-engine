# AI Policy for Hands-Off Engine

Any AI, agent, or automation working on this repository MUST:

1. First read:
   `termux-hands-off/docs/HANDS_OFF_RESEARCH_REPORT_2025-11-20.md`

2. Treat that document as the current canonical status + roadmap.

3. Align all plans, refactors, and changes with that roadmap unless explicitly
   instructed otherwise in a newer document or config.

4. Understand user communication patterns:
   `docs/USER_COMMUNICATION_GUIDE.md`
   
   This explains how the user (Yair) interacts with the system and what
   communication channels are available. When implementing features that
   involve user interaction, follow these established patterns.
