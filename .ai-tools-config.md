# AI Tools Configuration Reference

This repo includes automatic configuration for multiple AI coding tools.

## Files and What They Do

| File | Tool | Behavior |
|------|------|----------|
| `.ai-session-init` | Generic AI tools | General session bootstrap instructions |
| `.claude/instructions.md` | Claude Code CLI | Auto-loaded on session start |
| `.cursorrules` | Cursor IDE | Applied to all AI interactions |
| `.aider.conf.yml` | Aider | Auto-loads context files and applies settings |
| `AI_POLICY.md` | All tools | Machine-readable policy file |
| `state/knowledge.json` | Custom integrations | Structured data for AI-runner/MBOL |

## What They All Enforce

Every tool configuration ensures the AI:

1. **Reads the research report first:** `termux-hands-off/docs/HANDS_OFF_RESEARCH_REPORT_2025-11-20.md`
2. **Follows the documented roadmap** instead of making independent architectural decisions
3. **Uses Termux-compatible solutions** (no systemd, Docker, or root-required tools)
4. **Aligns with the project philosophy:** AI agents do the work, humans provide strategic direction

## For Other Tools

If you're adding a new AI coding tool:

1. Check if it supports auto-loading config files
2. Point it to:
   - `AI_POLICY.md` for policy
   - `state/knowledge.json` for structured bootstrap data
   - The research report for current status/roadmap
3. Add a new entry to this file documenting the config

## Manual Override

All configs can be temporarily overridden by explicit user instruction in a session.
The configs provide **defaults**, not hard constraints.
