# Execution Plan Notifications

**Status:** ✅ Implemented (2025-11-20)
**Purpose:** Push execution plans to Telegram/IFTTT for mobile review

---

## Overview

After the Decider generates trading plans and the Executor validates them, this system automatically pushes a mobile-friendly summary to your notification channels.

**Flow:**
```
Alpha Signals → Decider → Executor Plan → Notification → You (mobile)
```

---

## Files

| File | Purpose |
|------|---------|
| `termux-hands-off/agent/notify_execution_plan.py` | Main notification script |
| `termux-hands-off/agent/ho-executor-notify.sh` | Wrapper to call after executor |
| `executor/execution_plan.json` | Source data (generated by executor) |

---

## Notification Format

**Example message sent to Telegram:**

```
🔵 DRYRUN Execution Plan

📊 Summary: 3 orders, $75 total
⏰ 2025-11-18T03:07:42

Orders:
1. [macro] CPI drops below 2.5% by June?
   buy_yes • $25 • Edge: 10.0%
2. [crypto] Ethereum reaches $5k by Q1?
   buy_yes • $25 • Edge: 10.0%
3. [macro] Fed cuts rates by 0.25% in Dec?
   buy_yes • $25 • Edge: 15.0%

📍 Review full plan in execution_plan.json
```

**Mobile-friendly features:**
- Emoji headers for quick scanning
- Truncated questions (max 50 chars)
- Key info: category, side, size, edge
- DRYRUN vs LIVE mode clearly marked

## Configuration

### Telegram (Primary)

**Env file locations** (checked in order):
1. `~/hands-off/state/tg/bots/handsoff.env`
2. `~/hands-off/handsoff.env`
3. `termux-hands-off/handsoff.env`

**Required variables:**
```bash
TOKEN=123456:ABC-DEF...          # Telegram bot token
CHAT_ID=987654321               # Your Telegram chat ID
```

**Setup:**
1. Create Telegram bot via @BotFather
2. Get bot token
3. Send a message to your bot
4. Get chat ID: `https://api.telegram.org/bot<TOKEN>/getUpdates`
5. Save to env file

### IFTTT (Optional)

**Env file locations:**
1. `~/hands-off/ifttt.env`
2. `termux-hands-off/ifttt.env`

**Required variables:**
```bash
IFTTT_WEBHOOK_KEY=abc123...      # IFTTT webhook key
IFTTT_EVENT_NAME=execution_plan  # Event name (default: execution_plan)
```

**Setup:**
1. Go to https://ifttt.com/maker_webhooks
2. Get your webhook key
3. Create applet: "If Maker Event, Then Notification"
4. Save to env file

## Troubleshooting

### "No notification credentials found"

**Cause:** Neither Telegram nor IFTTT env files exist.

**Fix:** Create at least one env file (see Configuration above).

### "Execution plan not found"

**Cause:** `executor/execution_plan.json` doesn't exist.

**Fix:** Run executor first:
```bash
termux-hands-off/agent/ho-executor-plan.sh
```

### "Telegram API error"

**Cause:** Invalid token or chat ID.

**Fix:**
1. Check env file has correct TOKEN and CHAT_ID
2. Test bot manually: send message to bot, check for response
3. Verify chat ID with getUpdates API

### Message not sent but script succeeds

**Cause:** Silent failure in notification library.

**Debug:**
```bash
# Run with Python verbose mode
python3 -v termux-hands-off/agent/notify_execution_plan.py

# Check output for [ok] or [err] lines
```

## Message Customization

Edit `notify_execution_plan.py` function `format_execution_plan()` to customize:

**Available fields per order:**
- `candidate_id` - Internal ID
- `question` - Market question
- `side` - buy_yes or buy_no
- `size_usd` - Dollar amount
- `score` - Alpha score (0-1)
- `edge` - Expected edge percentage
- `category` - Market category
- `reason` - Why this trade makes sense
- `status` - planned/executed/rejected

**Example customization:**
```python
# Add score to message
lines.append(
    f"{i}. [{category}] {question}\n"
    f"   {side} • ${size} • Edge: {edge:.1%} • Score: {score:.3f}"
)
```

## Architecture Notes

**Why separate from executor?**
- Executor should focus on planning/validation logic
- Notifications are an output layer
- Easier to swap notification channels
- Can send to multiple channels in parallel

**Why not embed in executor?**
- Separation of concerns
- Executor can be tested without notifications
- Different cadences (executor runs often, notifications as needed)
